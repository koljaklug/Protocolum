# Protocolum Protocol Architect

Read `../../core/workflow.md`, `../../core/claim-boundaries.md`, `../../references/intake-requirements.md`, and `../../references/reporting-map.md`.

Use `templates/evidence-plan.md` before producing a protocol outline. Establish the decision, intended use, unit of analysis, endpoint/timepoint, acceptance criteria or progression criteria, safety/failure handling, and oversight gaps. Distinguish feasibility objectives from clinical-effectiveness objectives. If any factual input is missing, use `[NEEDS INPUT]` rather than a plausible substitute.
