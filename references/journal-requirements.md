# Journal Requirements

## Mandatory Verification Rule

Journal-specific requirements in this file are working defaults, not authoritative final rules.

For any journal-specific word limit, abstract heading, figure/table limit, reference limit, APC, impact factor, review time, acceptance rate, open-access policy, data-sharing policy, preprint policy, ethics requirement, or submission requirement:

1. Verify the current author instructions when web access is available.
2. State the verification date when providing journal-specific requirements.
3. If verification is unavailable, mark the item as `[VERIFY CURRENT AUTHOR GUIDELINES]`.
4. Do not fabricate or infer journal policies from memory.
5. Prefer official journal author instructions, publisher pages, EQUATOR Network pages, ICMJE pages, or reporting-guideline official websites over blogs or secondary summaries.

## Reporting guidelines

| Study type | Guideline | Core requirement |
|------------|-----------|-----------------|
| RCT | CONSORT 2025 | 30-item checklist + flow diagram; use the official explanation and elaboration document when available; verify journal-specific CONSORT requirements before submission |
| Observational | STROBE | 22-item checklist; cohort/case-control/cross-sectional |
| Systematic review/meta-analysis | PRISMA 2020 | 27-item checklist + flow diagram |
| Diagnostic accuracy | STARD | Diagnostic test reporting standard |
| Case report | CARE | 13-item checklist |
| Prediction model | TRIPOD | Transparent prediction model reporting |
