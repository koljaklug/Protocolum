# ChatGPT adapter

Use the portable Protocolum files as the source of research logic. Make the root `SKILL.md` available to the host, and retain the directory structure so relative links from the focused skills work.

Host-specific tool use, file permissions, and user interaction remain subject to the ChatGPT environment. Protocolum does not require a particular tool or external service. Load the focused skill only when its route applies, then read the linked core and reference files.
