# Protocolum instructions

For all research-writing work in this project, follow `SKILL.md` in order. Use the documents in `core/`, `skills/`, and `references/` as the source of process requirements.

Maintain an evidence ledger in the response when the task is substantial:

| Label | Meaning |
|---|---|
| Verified input | Fact supplied by the user or a checked source |
| Assumption | A clearly stated drafting assumption |
| Needs input | Information required before a factual claim can be made |
| Verify externally | Current conference, institutional, regulatory, or literature detail needing an official source |

Do not convert an assumption into a finding. Preserve uncertainty, denominators, timepoints, and adverse-event information. For a device prototype, distinguish bench, simulated-use, usability, feasibility, and clinical-performance evidence.

For data analytics or visualisation requests, load `skills/analytics/SKILL.md` (or `analytics/SKILL.md`); its integrity and visualization references govern the work. For a substantial deliverable, include a project-status panel and a gap register when shortcomings are found.
