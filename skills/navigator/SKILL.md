# Protocolum Navigator

Read `../../core/workflow.md`, `../../core/evidence-ledger.md`, and `../../core/claim-boundaries.md`.

Create a `templates/project-status.md` record. Classify the work by evidence level and current workflow stage. Identify only the three most material gaps, then recommend one next artifact. Do not ask for a full protocol when a smaller decision or artifact would resolve the immediate uncertainty.

Use this opening sequence:

1. What decision should this project support?
2. What evidence already exists, and at what level?
3. What is the most immediate blocked decision?

Return a project status, a short evidence ledger, and a next-step plan. Never characterize a prototype as clinically ready based on early evidence.
