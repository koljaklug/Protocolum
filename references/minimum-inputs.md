# Minimum Required Inputs

## General rule

Before producing substantive medical manuscript content, check whether the minimum inputs for the task are available.

If essential inputs are missing:
- ask up to 3 targeted questions; or
- proceed only if the user explicitly requests a rough draft, and mark assumptions clearly.

## Abstract

Essential:
- study design
- population/sample size
- intervention/exposure or main variable
- primary outcome
- key results with numbers
- conclusion supported by results

Ask before drafting if study design, population, primary outcome, or key results are missing.

## Methods

Essential:
- study design
- setting and study period
- participant/source population
- inclusion and exclusion criteria
- intervention/exposure definition
- primary and secondary outcomes
- statistical analysis approach
- ethics approval and consent status
- trial registration status, if applicable

Ask before drafting if study design, participants, outcomes, or ethics status are missing.

## Results

Essential:
- analyzed sample size
- baseline characteristics or descriptive summary
- primary outcome results
- secondary outcome results, if any
- effect estimates with 95% CI, if available
- adverse events/safety results, if relevant

Do not invent numbers. If a number is absent, write `[NEEDS DATA]`.

## Discussion

Essential:
- principal findings
- comparison literature or known context
- strengths
- limitations
- clinical or scientific implications

If prior literature is not provided and web access is unavailable, avoid specific citation claims.

## Sample size

Essential:
- study design
- primary outcome type
- effect size or expected difference
- alpha
- power
- allocation ratio, if applicable
- dropout/loss-to-follow-up assumption
- statistical test/model

Do not calculate a numeric sample size when core parameters are missing.

## Systematic review/meta-analysis

Essential:
- review question/PICO
- databases searched
- search date range
- inclusion/exclusion criteria
- screening process
- number of included studies
- risk-of-bias tool
- synthesis method
- registration status, if any

## Case report

Essential:
- patient age/sex, de-identified
- chief complaint/presentation
- diagnostic assessment
- intervention/treatment
- outcome/follow-up
- patient consent status

If identifiable patient details are present, ask user to de-identify before proceeding.

## Rebuttal

Essential:
- reviewer comment
- author's intended response or actual manuscript change
- location of change if available

If no manuscript change is provided, propose a response and mark the change location as `[ADD PAGE/LINE]`.
