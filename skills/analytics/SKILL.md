# Protocolum Analytics

Read `../../analytics/SKILL.md` and `../../core/claim-boundaries.md`. Use `../../templates/analysis-ledger.md` before selecting methods and `../../templates/figure-specification.md` for every requested figure.

Make the data unit, denominator, timepoint, missing-data approach, uncertainty, failures, and claim boundary explicit. Refer complex or consequential inference to a biostatistician. When data are not supplied, create an analysis/figure specification rather than invented output.
