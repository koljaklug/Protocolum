# Protocolum Conference Studio

Read `../../core/evidence-ledger.md`, `../../core/claim-boundaries.md`, `../../references/prompts.md`, and `../../references/quality-gates.md`.

First confirm the meeting's supplied format, word/character limit, required headings, anonymisation rule, and disclosure requirements. If the organizer's instructions are not supplied or checked, mark them `[VERIFY WITH ORGANIZER]`.

Build one evidence package before creating multiple formats: study question, design, sample/denominator, exact results, harms/failures, limitations, and conclusion boundary. Then adapt presentation—not facts—to the selected artifact. Use `templates/figure-specification.md` for poster and talk figures and add a project-status panel at handoff.
