## 扩展开发规范

1. **工具型功能独立成脚本**: 当扩展功能需要调用外部 API、执行数据计算或文件操作时，应开发为独立 Python/R 脚本，通过技能文档中的指令调用
2. **Prompt 与脚本分离**: 保持 Prompt 模板（文本生成）与数据处理脚本（逻辑计算）的职责分离
3. **向后兼容**: 新增模块不得影响现有 Prompt 的编号与调用方式
4. **版本管理**: 扩展模块纳入版本号管理（如 v0.9.1 增加模块九、十）
5. **配置化**: 期刊要求、术语库等数据采用外部配置文件（JSON/YAML），便于更新
