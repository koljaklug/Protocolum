# Evidence ledger

Use this ledger in substantial Protocolum work. It prevents a plausible draft from becoming an unsupported account.

| Label | Meaning | Permitted use |
|---|---|---|
| Verified input | User-supplied fact or checked source | May appear as a factual statement |
| Assumption | Explicit drafting or planning assumption | May appear only with a label |
| Needs input | Required detail is absent | Use a field, question, or placeholder—not a claim |
| Verify externally | Current requirement or source needs official confirmation | Do not finalize as fact |
| Exploratory finding | Observation not pre-specified or not definitive | Describe as exploratory, not confirmatory |

For each material conclusion, record: conclusion, supporting inputs, evidence level, qualifiers, and reviewer needed.
