## 1. 安装配置

### 1.1 Trae 用户

```bash
# 1. 克隆仓库
git clone https://github.com/Neuro-S/MedPen.git

# 2. 复制到 Trae skills 目录
cp -r MedPen ~/.trae/skills/

# 3. 重启 Trae 或发送 /reload
```

### 1.2 OpenClaw 用户

```bash
# 1. 克隆仓库
git clone https://github.com/Neuro-S/MedPen.git

# 2. 复制到 OpenClaw skills 目录
cp -r MedPen ~/.openclaw/skills/

# 3. 重启 OpenClaw 或发送 /reload
```

### 1.3 手动使用（任意 AI 工具）

无需安装，直接打开 `references/prompts.md` 文件，复制需要的 Prompt 到 Claude、ChatGPT、Cursor 等工具中使用。

## 3. Prompt 使用详解

### 3.1 Prompt #1: 临床研究设计咨询

**适用场景**: 你有一个临床问题，但不确定用什么研究设计

**输入示例**:
```
研究问题：脑出血后早期血压管理对预后的影响
研究对象：急性自发性脑出血患者
可用资源：单中心回顾性数据，约 500 例
目标期刊级别：Stroke 或 J Stroke Cerebrovasc Dis
```

**输出**: 推荐研究设计（回顾性队列研究）、详细方案框架、样本量建议

---

### 3.2 Prompt #8: 中文学术论文英译

**适用场景**: 你有中文草稿，需要投稿英文期刊

**输入**: 直接粘贴中文论文段落

**注意事项**:
- 医学术语自动使用 MeSH 标准译法
- 首次出现缩写必须写全称
- 数字与单位间留空格（5 mL, 10 mg）
- P 值大写斜体 P

---

### 3.3 Prompt #17: 审稿人意见回复

**适用场景**: 收到审稿意见，需要撰写 Rebuttal

**输入**: 逐条粘贴审稿人意见

**输出格式**:
```
## Response to Reviewer #1

### Comment 1: [审稿人意见]
**Response:** 感谢审稿人的意见...[详细回复]
**Action taken:** 已在 Section X.X (Page Y, Line Z) 修改
```

## 5. 质量闸门说明

MedPen 在执行任务前后会自动运行质量检查：

### 执行前检查

1. **安全合规检查** — 检查患者隐私、数据完整性、伦理合规
2. **最低输入检查** — 确认是否提供了完成任务所需的最低信息
3. **统计完整性检查** — 确认统计方法与研究设计匹配

### 执行后检查

4. **报告规范对齐** — 确认内容符合 CONSORT/STROBE/PRISMA 等规范
5. **翻译准确性** — 确认术语、缩写、统计符号符合目标语言规范
6. **输出完整性** — 确认所有请求部分已完成，无遗漏

如果任何检查未通过，AI 会提示用户补充信息或修正问题。

## 6. 常见问题

### Q1: 我的 AI 工具不支持 Skill 格式怎么办？

**A**: 直接打开 `references/prompts.md`，复制你需要的 Prompt 内容，粘贴到任何 AI 工具中使用。Prompt 本身是纯文本，兼容所有主流 AI。

### Q2: 可以只使用部分 Prompt 吗？

**A**: 完全可以。每个 Prompt 都是独立的，你可以根据当前需求选择使用。参考 README 中的"子流程快速入口"表格。

### Q3: 如何修改 Prompt 以适应我的专科？

**A**: 打开 `references/prompts.md`，找到对应 Prompt，修改 Role 定义中的专科描述。例如将"神经外科"改为"心血管内科"。

### Q4: 未来会支持自动参考文献格式化吗？

**A**: 已在路线图 docs/ROADMAP.md 中规划（模块九），预计 v0.9.0-preview 版本实现。

### Q5: 使用这个技能需要编程基础吗？

**A**: 当前 v0.9.0-preview 版本完全不需要编程基础，所有功能通过自然语言 Prompt 实现。未来脚本增强功能也只需复制命令运行。

### Q6: AI 会编造数据吗？

**A**: MedPen 内置安全合规规则，严禁编造患者数据、统计值或参考文献。如果数据缺失，AI 会标记 `[NEEDS DATA]` 并要求你补充。
